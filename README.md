# pyxel-dog

Fun Python scripts for the Pyxel robot dog toy! 🐕🤖

## About

This repository contains a collection of entertaining and educational Python scripts for the Pyxel dog. Each script demonstrates different capabilities including movement, LED animations, sensor interactions, and more.

## Quick Start

All scripts use the standard Pyxel initialization:

```python
from pyxel import Pyxel
pyxel = Pyxel()
```

## Available Scripts

The `scripts/` directory contains 6 fun scripts:

1. **01_basic_movements.py** - Learn the fundamental movement commands
2. **02_dance_party.py** - Watch your dog dance with LED effects
3. **03_led_animations.py** - Showcase of colorful LED patterns
4. **04_guard_dog.py** - Security patrol with sensor alerts
5. **05_fetch_game.py** - Play an automated fetch game
6. **06_obstacle_course.py** - Navigate a challenging course

See the [scripts/README.md](scripts/README.md) for detailed documentation of each script.

## Usage

Copy any script to your Pyxel dog editor and run it to see the behavior in action!

## Features

- 🚶 Movement and navigation
- 💡 LED light animations
- 🎵 Sound effects
- 🎯 Sensor-based behaviors
- 🎮 Interactive games
- 🎪 Dance routines
